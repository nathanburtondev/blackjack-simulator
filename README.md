# Blackjack Probability Simulator

A Python-based Monte Carlo simulation that calculates real-time blackjack probabilities based on the player's current hand and dealer upcard.

## Overview
This project simulates 1000+ blackjack hands in parallel to estimate probabilities for different outcomes and help guide player decisions.

## Features
- Real-time probability calculations
- Monte Carlo simulation approach
- Supports standard blackjack rules
- Interactive gameplay

## Tech Stack
- Python
